  ℹ tests 113   ℹ pass 113   ℹ fail 0   ℹ cancelled 0   ℹ skipped 0   ℹ todo 0
  ℹ duration_ms 32180.572384

- **`113` 这个数字必须带口径读**（重要，别当成 113 个细粒度断言）：
  - `tests/*.test.mjs` 共 **96 个文件**；
  - 其中 **9 个**用 `node:test`（`grep -l "node:test"`），**87 个**是裸 assert 脚本（`grep -L`）；
  - `grep -rhE "^(test|it)\("` 只有 **26 个命名用例**；
  - `node --test` 把每个裸脚本整个算作 1 项（输出形如 `✔ tests/utterance.test.mjs (201ms)`），故 `26 + 87 = 113`。
  - 含义：**113 = 26 个细用例 + 87 个文件级整体通过**。裸脚本里的断言若抛出，会让该文件整项失败；但它没有用例名，失败定位粒度粗。
- 另：本插件 `package.json` **没有 `scripts.test`**（`node -e "require('./package.json').scripts"` → `undefined`），所以本版验证靠上面那条手写命令，没有 `npm test` 入口。
- **未复跑的理由（不是省略）**：`lib/index.js` 的 mtime 为 `2026-11-15 13:25:59`，本版跑完后 `lib/` 与 `tests/` 无改动（`find … -newermt '-30 minutes'` 对 memory 无命中），故 22:55 那次的 113 即为当前工作树结果。
